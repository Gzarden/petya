# Петя — голосовой помощник для бега (Android)

Работает в фоне офлайн (Vosk), слушает слово «Петя» и выполняет команды:
ответить/сбросить звонок, позвонить контакту, следующий/предыдущий трек,
тише/громче, пауза, включить музыку (Яндекс.Музыка), открыть любое приложение
(«Петя, включи антирадар»), «который час».

## Как получить APK без Android Studio
1. Загрузите проект в репозиторий GitHub (ветка `main`).
2. Откройте вкладку **Actions** → **Build APK** → дождитесь зелёной галочки (3–6 мин).
3. Откройте завершённый запуск → внизу **Artifacts** → скачайте `Petya-apk` (zip с `Petya.apk`).
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

Свой релиз со ссылкой для скачивания: создайте тег, например `v1.0`
(**Releases → Draft a new release → Choose a tag → Create new tag**) — APK появится в релизе.

## После установки
Нажмите «Запустить», выдайте разрешения, затем включите
«Поверх других окон» и «Не усыплять в фоне».

## Свои команды
Файл `app/src/main/java/com/petya/assistant/CommandHandler.kt`:
слова для приложений — список `aliases`, пакет плеера — `musicPackage`.

## Нажатие кнопок в других приложениях (Play, Старт, Отправить)
Включите **Настройки → Спец. возможности → Петя**. На Android 13+ при установке из APK пункт может быть серым:
**Настройки → Приложения → Петя → ⋮ → «Разрешить ограниченные настройки»**, затем повторите.
Названия кнопок: `ClickService.kt` (`PLAY`) и `CommandHandler.kt` (`startLabels`, `stopLabels`).
Не нажимается кнопка? Откройте нужный экран и скажите «Петя, что на экране» — список появится в приложении.

## Распознавание речи (Vosk)
Модель `vosk-model-small-ru-0.22` скачивается автоматически при сборке в GitHub Actions и кладётся в APK
(размер APK ~60 МБ). При первом запуске модель распаковывается — подождите до минуты.
Основные команды распознаются по узкой грамматике (`FIXED` в `AssistantService.kt`) — это самый надёжный режим.
Имена, приложения и текст сообщений — полным распознаванием.

## Нейросеть GigaChat (необязательно)
Если фраза не подошла ни одной команде, она уходит в GigaChat (Сбер), который превращает её в команду
или отвечает коротким текстом. Ключ: developers.sber.ru → Studio → проект GigaChat API → «Настройки API»
→ «Ключ авторизации». Вставьте его в приложении в поле «Ключ GigaChat».
Сертификат Минцифры (нужен для связи с GigaChat) скачивается и встраивается при сборке в GitHub Actions.
