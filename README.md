# Петя — голосовой помощник для бега (Android)

Работает в фоне, слушает слово «Петя» и выполняет команды:
ответить/сбросить звонок, позвонить контакту, следующий/предыдущий трек,
тише/громче, пауза, включить музыку (Яндекс.Музыка), открыть любое приложение
(«Петя, включи антирадар»), «который час».

## Как получить APK без Android Studio
1. Загрузите проект в репозиторий GitHub (ветка `main`).
2. Откройте вкладку **Actions** → **Build APK** → дождитесь зелёной галочки (3–6 мин).
3. Откройте завершённый запуск → внизу **Artifacts** → скачайте `Petya-apk` (zip с `Petya.apk`).
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

Свой релиз со ссылкой для скачивания: создайте тег, например `v1.0`
(**Releases → Draft a new release → Choose a tag → Create new tag**) — APK появится в релизе.

## После установки
Нажмите «Запустить», выдайте разрешения, затем включите
«Поверх других окон» и «Не усыплять в фоне».

## Свои команды
Файл `app/src/main/java/com/petya/assistant/CommandHandler.kt`:
слова для приложений — список `aliases`, пакет плеера — `musicPackage`.
